# Bankee

A React (JavaScript) starter powered by Vite, Tailwind CSS 4, and Motion. The UI/UX Pro Max skill is installed locally under `.agents/skills/ui-ux-pro-max/`, and project guidance for future Codex prompts lives in `AGENTS.md`.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite. To check a change, run:

```bash
npm run lint
npm run build
```

## Project layout

- `src/App.jsx` — starter screen and Motion example
- `src/index.css` — Tailwind import and global styles
- `vite.config.js` — React and Tailwind Vite plugins
- `AGENTS.md` — project context for future agent tasks
- `.agents/skills/ui-ux-pro-max/` — repository-local UI/UX skill

The starter screen is intentionally generic. Add product requirements and design decisions to `AGENTS.md` as they become clear.
