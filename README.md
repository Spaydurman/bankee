# Ban Kee Trading website redesign

A responsive React/Vite draft for Ban Kee Trading, Inc., built with Tailwind CSS 4 and Motion. The page presents Ban Kee as a Philippine distributor for retail and brand partners, using the company's existing copy, brands, partner names, and visual materials.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run lint` and `npm run build` before shipping changes.

## Content and assets

- Company history, business areas, partner names, address, hours, and contact details were checked against [bankee.com.ph](https://bankee.com.ph/).
- Product and brand images in `public/images/` were copied from the existing Ban Kee website, including its [LEGO](https://bankee.com.ph/lego), [Intex](https://bankee.com.ph/intex), and [Blokees](https://bankee.com.ph/blokees) pages.
- The two social images and linked highlights came from public posts on [Ban Kee Toys on Facebook](https://www.facebook.com/bankeetoys.ph), reviewed in October 2026. They are curated examples, not an automatically updated feed.
- The site currently uses `mailto:` links for partner inquiries. There is no form service or CMS integration.
